Generador de cotizaciones – Nexa Digital

Descripción del proyecto

Este proyecto permite gestionar cotizaciones de productos y servicios de la empresa ficticia Nexa Digital, mediante una aplicación desarrollada en Python y Streamlit.

Funcionalidades

- Crear: registrar nuevas cotizaciones.
- Consultar: visualizar las cotizaciones guardadas.
- Actualizar: modificar cotizaciones existentes.
- Eliminar: borrar cotizaciones.
- Calcular totales: obtener automáticamente el valor total de cada cotización.
- Generar PDF: descargar las cotizaciones en formato PDF.
- Guardar información: conservar los registros mediante un archivo JSON.

Tecnologías utilizadas

- Python
- Streamlit
- JSON
- ReportLab

Cómo ejecutar el proyecto

1. Descargar el proyecto desde GitHub.

2. Abrir la carpeta en Visual Studio Code.

3. Abrir la terminal.

4. Instalar las dependencias:
   
   pip install streamlit reportlab

5. Ejecutar la aplicación:
   
   python -m streamlit run main.py

6. La aplicación se abrirá en el navegador.
